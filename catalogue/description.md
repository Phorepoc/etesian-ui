Etesian is the Etesian design language (the N9's look, re-envisioned) as a second shell for the Symbian^3 UI. This is an early release.

It installs on top of the standard UI and changes nothing in it. After installing, open the "Etesian shell" app, pick Etesian and
restart: you get the Etesian Home with its app grid, a dark skin, Fira Sans, and a dialler; the standard applications keep working
under it. Pick the standard shell the same way to go back. If Etesian does not start, the phone falls back to the standard
shell by itself. Removing the package removes the Etesian shell and leaves the Symbian^3 UI as it was.

Apache-2.0; Fira Sans is SIL OFL 1.1 and the icons are MIT. The licences are installed in `\resource\etesian\licences\`.
